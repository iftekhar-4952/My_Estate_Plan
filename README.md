# My Estate Plan Website

Static GitHub Pages website for the My Estate Plan iOS app.

## Files
- index.html — homepage
- privacy.html — Privacy Policy
- terms.html — Terms & Conditions
- support.html — support page
- styles.css — responsive design
- script.js — mobile navigation, current year, support email

## Before publishing
Open `script.js` and replace `YOUR_SUPPORT_EMAIL@example.com` with the real support email address used by the app.

Review the Privacy Policy and Terms against the exact production build, especially if you add analytics, crash reporting, cloud sync, advertising, subscriptions, or other third-party services.

## GitHub Pages
1. Create a repository.
2. Upload all files to the repository root.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Select your branch and `/ (root)`.
6. Save.

No build step is required.
